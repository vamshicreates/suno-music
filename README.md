# Suno Music

**Describe the song that you want, and we will generate the lyrics and give you the complete style.**

Suno Music is a Claude skill for Suno. Tell it what you want in one line, for example *"a Telugu devotional song for Lord Venkateswara, female voice, calm"* or *"a Hindi Hanuman bhajan, male, energetic"*. You get back original lyrics plus the complete setup (title, style prompt, exclude styles, slider values, model and tagged lyrics), ready to paste and press **Create**.

- Tuned for **Telugu and Hindi** (native-script lyrics, Indian instrument and genre tags), and works for any language.
- Built from Suno's own documentation (November 2026) and tested prompting practice.
- Counts every field against the app's character limits before handing it over.

## Install

**Claude Code**
```bash
git clone https://github.com/vamshicreates/suno-music ~/.claude/skills/suno-music
```

**Claude app (claude.ai / desktop)**: download this repo as a ZIP, then upload it under *Settings → Capabilities → Skills*.

## Use

> Make a Suno song: Telugu folk wedding song, male and female duet, upbeat.
